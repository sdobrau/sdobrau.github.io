# Introduction

To practice JavaScript and Chrome extension development, I made a
little extension that displays the corresponding flag near each
international phone number.

The code can be found [here](https://github.com/sdobrau/Phone-flags).

This is what it looks like:

![Phone flags screenshot](../../images/phone-flags-screenshot.png)

# Features

* [x] All places covered in [this Wikipedia link](https://en.wikipedia.org/wiki/List_of_telephone_country_codes).
* [x] Works for various formats, such as with/without plus, hyphens,
  spaces or leading 00.
* [x] Flags for each state of the USA

# Conclusion

I enjoyed writing this extension as it has given me more confidence
in working with data structures and writing regular expressions. I
hope this extension offers increased quality of life to whoever needs
it.
